SPOTIFY
Для асинхронного обмена данными между микросервисами Spotify использует Apache Kafka. Через Kafka система в реальном времени собирает и передаёт события: пользователь включил трек, поставил лайк, создал плейлист. На основе этих потоков строятся рекомендации, обновляются профили пользователей, работают другие динамические функции. Для синхронных запросов (например, при авторизации или поиске) сервисы общаются через REST API или gRPC
